# Legal AI Backend Boilerplate 🚀

A production-grade, async **FastAPI** backend engineered for LegalTech and AI-powered legal assistance, with **PostgreSQL** (for lawyer accounts, legal cases, and chat sessions) and **Weaviate** (for vector storage & semantic search), configured for **1-click free deployment on [Render.com](https://render.com)**.

---

## 🏛️ Database Schema Architecture

The backend implements the following relational schema:

```
[ users ] (Lawyers / Users)
   ├── id: UUID (PK)
   ├── email: VARCHAR(255) (UNIQUE)
   ├── password_hash: VARCHAR(255)
   ├── full_name: VARCHAR(100)
   ├── bar_council_id: VARCHAR(50) (Optional lawyer verification)
   └── created_at, updated_at: TIMESTAMPTZ
         │ (1 to Many, Cascade Delete)
         ▼
[ projects ] (Cases)
   ├── id: UUID (PK)
   ├── user_id: UUID (FK -> users.id) [INDEXED: idx_projects_user_id]
   ├── title: VARCHAR(255) (e.g. "State vs. Reliance")
   ├── description: TEXT (Case facts & notes)
   └── created_at, updated_at: TIMESTAMPTZ
         │ (1 to Many, Cascade Delete)
         ▼
[ threads ] (Chat Sessions)
   ├── id: UUID (PK)
   ├── project_id: UUID (FK -> projects.id) [INDEXED: idx_threads_project_id]
   ├── title: VARCHAR(255) (e.g. "Drafting Bail", "Cross-Exam Prep")
   └── created_at, updated_at: TIMESTAMPTZ
```

## 🛠️ Alembic Migration & Version Management

This repository uses **Alembic** with asynchronous SQLAlchemy for database version control.

### Scenario A: Your Cloud PostgreSQL Already Has These Tables
If you already executed your `.sql` file in your Cloud PostgreSQL database:
1. Make sure your `.env` contains your `DATABASE_URL`.
2. Stamp the database to tell Alembic it is at the latest revision **without re-running `CREATE TABLE`**:
   ```bash
   alembic stamp head
   ```
   *This creates the `alembic_version` table and marks revision `0001_initial_legal_schema` as applied.*

### Scenario B: Fresh Database (Local, Docker, or New Cloud DB)
To create all tables, indexes, and constraints from scratch:
```bash
alembic upgrade head
```

### Scenario C: Making Future Schema Changes
1. Modify your SQLAlchemy models in `app/models/`.
2. Generate an autogenerated migration script:
   ```bash
   alembic revision --autogenerate -m "Add hearing_date to projects"
   ```
3. Review the generated script in `alembic/versions/`.
4. Apply the migration:
   ```bash
   alembic upgrade head
   ```

## 🌟 Key Features

- **FastAPI Framework**: Modern async architecture with Pydantic v2 validation, CORS configuration, and interactive documentation (`/docs`, `/redoc`).
- **Legal Entity Endpoints**:
  - **Auth**: `/api/v1/auth/register`, `/api/v1/auth/login`, `/api/v1/auth/me`.
  - **Cases/Projects**: Full CRUD at `/api/v1/projects` (isolated per lawyer).
  - **Chat Threads**: Create, list, update, and delete sessions at `/api/v1/projects/{project_id}/threads`.
- **Weaviate v4 Vector Database**:
  - Integration with Weaviate v4 Python client.
  - Supports **Weaviate Cloud Services (WCS)** free sandbox or local Docker containers.
  - Hybrid search (BM25 keyword + semantic vector) and document chunk ingestion.
- **Render.com Ready**:
  - `render.yaml` Blueprint for free 1-click deployment (FastAPI web service + free PostgreSQL).
  - Production `Dockerfile` and dynamic `$PORT` handling.
- **Automated Tests**: Comprehensive test suite using `pytest` and `pytest-asyncio` with isolated in-memory test database.

## 🚀 Quickstart (Local Development)

### Method 1: Local Python Virtual Environment

1. **Activate virtual environment**:
   ```bash
   source .venv/bin/activate
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Set up environment variables**:
   ```bash
   cp .env.example .env
   # Edit .env with your DATABASE_URL
   ```

4. **Sync / Migrate database**:
   ```bash
   alembic upgrade head
   # (Or 'alembic stamp head' if tables already exist in your database)
   ```

5. **Start development server**:
   ```bash
   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   ```

6. **Interactive Documentation**:
   - Swagger UI: [http://localhost:8000/docs](http://localhost:8000/docs)
   - ReDoc: [http://localhost:8000/redoc](http://localhost:8000/redoc)

---

### Method 2: Docker Compose (Local Stack)

Spin up FastAPI with hot reload, PostgreSQL 16, and Weaviate v1.27:

```bash
docker compose up --build
```
